OurTeam Portfolio Website

1. About the Project

OurTeam is a WordPress portfolio website created to introduce our team, present each member’s professional role, and showcase our shared skills, goals, and project contributions.

The website was developed using a customized WordPress theme and is designed to be clean, responsive, and easy to navigate.

2. Website Content

The website includes:

- Homepage with an introduction to the team
- Team highlights and role summaries
- Individual member profile pages
- About section
- Team goals and achievements
- Contact section with member information and QR codes
- Blog and portfolio-related pages
- Responsive design for desktop and mobile users
